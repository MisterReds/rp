# Форматы данных

Все JSON — UTF-8. Коды пишутся единообразно: `ОК 01`, `ПК 5.1`, `МДК.05.01`, `УП.05`, `ПП.05`, `ПМ.05`.
Поля с `_` в начале — служебные (источник, заметки); программа их не печатает.

## Учебный план — `data/plans/ГРУППА.tsv`

Текст с табуляциями, первая строка может быть заголовком. Значимы строки с индексом в первом столбце:

```
Индекс  Наименование  Формы ПА  Максимальная  Самостоятельная  Обязательная  Теория  Практика  Курсовых  сем1  сем2  …
МДК.03.01  Эксплуатация …  ДЗ, Э  158  0  158  50  68  40  0  0  0  106  52  0
```
Формы — по семестрам с часами через запятую (`ДЗ, Э`), или одна форма (ставится в последний семестр), `-` — нет.
Обозначения: Э, ДЗ, З, ДР, КР, ЭК. Проверка: `tools/check_plan.py`.

## Паспорт — `projects/X/project.json`

Пути — относительно файла. Образец со всеми полями — `examples/PM05_OP-2301is/project.json`.

| Поле | Значение |
|---|---|
| `fgos`, `vospitanie`, `plan`, `pop` | пути к данным |
| `pm`, `group`, `form`, `year`, `course_offset` | модуль, группа, форма обучения, год, сдвиг курса |
| `org`, `pcc`, `people`, `pop_reg_number` | реквизиты титула и оборота |
| `competence` | компетенция «Профессионалы» |
| `vd_name` | точное название ВД, если вариантов несколько |
| `forms_override` | `{"ПП.05": null}` — ПП без зачёта; иные изменения форм — по указанию человека |
| `ok_lr_override` | `{"ОК 10": [15, 38, 41]}` — для ОК, которых нет в таблице программы воспитания |
| `vospitanie_prev` | путь к ЛР прошлого учебного года (`data/vospitanie/spet_2025-2026_09.00.00.json`) — если ПМ шёл и в прошлом, и в текущем году; таблицы ЛР выводятся по годам |
| `pop_mdk_map` | `{"МДК.02.03": "МДК.02.04"}` — МДК плана берёт темы из раздела ПОП с другим кодом (в плане меньше МДК, чем в ПОП) |
| `hints` | `general`, `mdk: {"МДК.05.01": "…"}`, `up` — пожелания человека |
| `llm` | `provider`, `base_url`, `model`, `api_key_env`, `temperature`, `json_mode` |
| `content`, `output` | файл наполнения и путь готового .docx |
