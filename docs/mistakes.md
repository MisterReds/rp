# Помарки, которые уже были, и как их не допустить

Каждая строка — реальная ошибка из работы над ПМ.01, ПМ.03 (09.02.06) и ПМ.05, ПМ.06 (09.02.07). Колонка «Ловит» — что её находит сейчас.

## Требования техникума (замечания методиста)

| Помарка | Как правильно | Ловит |
|---|---|---|
| Упоминание WorldSkills / «Молодые профессионалы» на обороте титула | только чемпионат «Профессионалы» | lint, check_docx |
| Таблица «Цифровые инструменты» в разделе 3 | не включается | check_docx |
| Таблица «Трудоёмкость освоения модуля», сноска под таблицей структуры | не нужны | check_docx |
| Портфолио в экзамене по модулю | практические задания по всем ПК | этап module_exam, lint, check_docx |
| Дифференцированный зачёт / «защита отчёта» по производственной практике | только отчёт по практике | этап pp, lint, check_docx |
| «Формы аттестации установлены учебным планом» | «в форме экзамена (4 курс, 1 семестр)» | check_docx |
| Часть работы ПОП на 3 пары — одним номером | № 3 (часть 1), № 4 (часть 2), № 5 (часть 3) | check_docx |
| «В том числе практических занятий» отдельной строкой | не пишется | build |
| Не все ЛР / ЛР прошлого года | все ЛР программы воспитания текущего года | check_docx |
| ФОС по видам контроля вперемешку | МДК по семестрам → УП → ПП → экзамен по модулю | build |
| Контрольная работа в 1–2 вариантах | ≥ 3–4 варианта с эталонами | этап cw |
| 15–25 тестовых вопросов и 8–12 задач на МДК — на группу из 30 человек не хватает | минимум 60 вопросов теста, 60 вопросов и 60 заданий к каждой аттестации, 60 вопросов к зачёту по УП | validate |
| Названия тем заменены названиями занятий | тема ПОП — заголовок с содержанием, под ней занятия | validate |
| МДК из готовой программы «приведён к ПОП», хотя велели взять как есть | custom-МДК, дословно из документа | reviewer |

| Помарка | Как правильно | Ловит |
|---|---|---|
| Занятие = название темы | конкретная дидактическая единица | этап themes, lint |

| Повтор названий занятий в МДК | все разные | этап themes, lint |
| Повтор заданий УП / дней ПП | все разные | этапы up, pp, lint |
| Вид работ практики перефразирован | посимвольно из ПОП | этапы up, pp |

| «Все ответы верны» в тесте | только конкретные варианты | этап tests, lint |
| Почти одинаковые вопросы теста / экзамена | разные единицы | этапы tests, exam, lint |
| Задача экзамена без исходных данных | действие + данные + результат | reviewer |
| Неверный ключ теста | решить каждый вопрос | reviewer |
| Тема разбита на 2 занятия, хотя в документе одно (custom-МДК, тема 2.3 ПМ.03) | как в документе | reviewer |
