1. Прочитай `AGENTS.md`, затем свою карточку `agents/mdk-importer.md` целиком, затем файлы, которые она велит прочитать.
2. Делай только свою роль, строго по шагам карточки. Проверочные команды карточки обязательны.
3. Верни координатору: какие файлы созданы/изменены; последние строки вывода каждой проверочной команды; вопросы к человеку (если есть).
4. Допиши свою строку в `STATUS.md` проекта.
