# Для агентов (Claude, Codex, Qwen и др.)

Задача репозитория — рабочая программа профессионального модуля СПО + ФОС одним .docx по шаблону ГБПОУ «СПЭТ».

1. Прочитай `ИНСТРУКЦИЯ.md` целиком (часть 1 — правила документа, часть 3 — программа).
2. Оформление делает только программа (`src/build.js`). Не собирай .docx вручную и не меняй структуру через другие инструменты — иначе оформление разойдётся с примером.
3. Порядок: `tools/pop_extract.py` (ПОП → `data/pop/*.json`) → `node src/cli.js new` → `init` → `fill` или `next`/`import` → `validate` → `build`.
4. Нельзя: менять темы, содержание тем, лабораторные работы и виды работ практик ПОП; менять часы учебного плана; ставить зачёт производственной практике; упоминать портфолио, WorldSkills, таблицу «Цифровые инструменты».
5. Эталон результата: `examples/PM01_OA-2401/` (`project.json`, `content.json`, готовый .docx). Сборка примера должна давать байт-в-байт тот же `word/document.xml`.
6. После `init` проверь замечания: коды МДК в файле ПОП должны совпадать с учебным планом; если практических пар в плане меньше, чем лабораторных работ ПОП, соседние работы одной темы объединяются автоматически.
