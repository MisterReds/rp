# Для агентов (Claude, Codex, Qwen, GPT и др.)

Репозиторий делает рабочую программу профессионального модуля СПО + ФОС одним .docx по шаблону ГБПОУ «СПЭТ»
для любой специальности: вход — учебный план группы, ФГОС, ПОП, программа воспитания; выход — готовый документ.

## Кто ты

- Если в задании названа роль («ты — pop-extractor», «выполни agents/reviewer.md») — открой её карточку в `agents/` и делай только её.
- Если роль не названа — ты **координатор**: `agents/orchestrator.md`.
- Если ты не умеешь запускать субагентов — выполняй роли сам по очереди, каждый раз заново открывая карточку роли.
  Роль `reviewer` делай в новом чате/сессии, если это возможно: проверяющий не должен видеть, как писалось наполнение.

## Что прочитать

| Файл | Зачем |
|---|---|
| `agents/README.md` | процесс целиком: роли, порядок, передача работы, когда остановиться |
| `agents/<роль>.md` | карточка своей роли: вход, выход, шаги, проверка готовности, запреты |
| `docs/rules.md` | правила документа — коротко, без исключений |
| `docs/style.md` | как писать тексты: занятия, задания практик, тесты, билеты, экзамен — с образцами |
| `docs/mistakes.md` | помарки, которые уже встречались, и как их не допустить |
| `docs/formats.md` | форматы JSON: план, ФГОС, ПОП, программа воспитания, project.json, content.json |
| `docs/practice_format.md` | как оформляются практики (таблица содержания УП/ПП и отдельные программы практик) — по образцам техникума |
| `ИНСТРУКЦИЯ.md` | полное описание для человека (часть 1 — требования, часть 3 — программа) |

## Пять правил, которые нельзя нарушать

1. Тексты ПОП и ФГОС переносятся **дословно**. Каждый JSON из исходника проходит `python3 tools/verify_sources.py` без ошибок.
2. Часы — **только** из учебного плана. МДК — пары по 2 ч; практики — пунктами со своими часами по образцу программ практик (УП кратно 2 ч, ПП кратно 6 ч).
3. .docx собирает **только** `node src/cli.js build`. Руками документ не правится и не собирается.
4. Готово = `validate`, `lint`, `build` без ошибок + `agents/reviewer.md` выдал «ПРИНЯТО».
5. Нет данных — не выдумывай: остановись и спроси человека (список случаев — `agents/README.md`, раздел «Стоп»).

## После изменений в коде

`node tools/selftest.js` — должно быть «Самопроверка пройдена» (проверяет примеры с собранным .docx; незавершённый — явным путём). Сборка `examples/PM01_OA-2401` должна давать тот же `word/document.xml`.
