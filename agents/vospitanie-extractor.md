# Роль: программа воспитания (vospitanie-extractor)

**Назначение.** Перенести личностные результаты (ЛР) и таблицу соответствия ОК–ЛР из рабочей программы воспитания
техникума на учебный год в `data/vospitanie/ФАЙЛ.json`.

**Вход:** рабочая программа воспитания (.docx/.pdf) на нужный учебный год.
**Выход:** `data/vospitanie/<техникум>_<год>-<год>.json`; при другом наборе ОК — `ok_lr_override` для project.json.
**Прочитать:** `docs/formats.md` → «Программа воспитания»; образец `data/vospitanie/spet_2026-2027.json`.

## Шаги

1. `python3 tools/doc2text.py sources/воспитание.docx sources/воспитание.txt`.
2. `lr`: все ЛР — `{"1": "текст", …, "52": "текст"}`, дословно, по порядку. Количество — сколько в программе (в СПЭТ 2026–2027 — 52).
   Копируй скриптом по номерам строк, не перепечатывай.
3. `ok_lr`: таблица соответствия ОК и ЛР (в СПЭТ — «Таблица 3»): `{"ОК 01": [39, 40, 47], …}` — номера ЛР числами.
4. `title` — название программы и учебный год; `source_table` — откуда таблица соответствия.
5. **ОК специальности не совпадают с ОК таблицы** (например, ФГОС 2016 г.: ОК 01–11, а таблица — по ОК 01–09):
   - сопоставь по смыслу формулировок ОК специальности и ОК таблицы (сравни тексты ОК во ФГОС специальности и в программе воспитания);
   - запиши в project.json: `"ok_lr_override": {"ОК 09": [...], "ОК 10": [...], "ОК 11": [...]}` и пояснение в `"_ok_lr_override"`;
   - у каждого ОК специальности — хотя бы один ЛР. Это решение помечается в STATUS.md как «проверить человеку».

## Проверка готовности

```
python3 tools/verify_sources.py data/vospitanie/ФАЙЛ.json sources/воспитание.txt
```
«не найдено в исходнике: 0». Плюс скриптом: число ЛР = числу в программе; номера 1…N без пропусков;
все номера в `ok_lr` существуют в `lr`.

## Запрещено

- Брать ЛР прошлого учебного года, если есть программа текущего.
- Сокращать формулировки ЛР.

## В STATUS.md

`Воспитание: data/vospitanie/ФАЙЛ.json; ЛР N; таблица ОК–ЛР: <источник>; ok_lr_override: нет / ОК … (проверить человеку).`
