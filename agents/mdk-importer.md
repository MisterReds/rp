# Роль: перенос МДК из готовой программы (mdk-importer)

**Когда.** Только если человек прямо велел: «МДК.03.01 взять из документа». Тогда этот МДК не строится по ПОП,
а переносится из присланной программы **как есть**: разделы, темы, содержание, занятия, курсовой, аттестация.

**Вход:** готовая рабочая программа (.docx), где есть КТП этого МДК; `content.json` после `init`.
**Выход:** МДК в `content.json` с `"custom": true` и явными занятиями `lessons`.
**Образец:** МДК.03.01 в `examples/PM03_OA-2401/content.json` (разделы, тема без названия, курсовой 40 ч этапами, ДЗ отдельной строкой).
**Прочитать:** `docs/formats.md` → «content.json: custom-МДК».

## Шаги

1. `python3 tools/doc2text.py sources/программа.docx sources/программа.txt`; найди КТП нужного МДК (строки `[tNNN rMM]`).
2. Скриптом (не руками) разложи строки КТП:
   - строка «Раздел N. …» → значение `section` у следующих тем;
   - строка «Тема N.M. Название» → новая тема: `num`, `name`, `section`, `content[]` (содержание темы из той же таблицы), `codes` (коды из столбца кодов);
   - строка занятия → `{"k": "T", "t": "название", "h": 2}`; практическая/лабораторная работа → `"k": "P"`;
     название — дословно, но без «Практическая работа № N.» (номера программа поставит сама);
   - занятие с аттестацией («Дифференцированный зачёт», «Экзамен» внутри КТП) → `{"k": "T", "t": "Дифференцированный зачёт", "h": 2, "att": true}`;
   - занятия без темы (в документе идут после темы без заголовка) → тема с `"num": "", "name": ""` и тем же `section`;
   - курсовой проект → `course_project: {"hours": K, "title": "Курсовой проект", "topics": [...], "stages": [["этап", 2], …]}`, этапы — как в документе, по 2 ч.
3. Заменить МДК в content.json: сохранить `code`, `name`, `T`, `P`, `K`, `sems` из каркаса (они из плана), добавить `"custom": true`, `themes` — из шага 2.
4. Занятие длиннее 2 ч в документе — если в документе так, оставь одной строкой с `h` как в документе и запиши в STATUS.md (так было с темой 2.3 в ПМ.03).

## Проверка готовности

- Сумма `h` у `k:"T"` = `T` МДК, у `k:"P"` = `P` МДК; курсовой = `K` (иначе `validate` даст ошибку).
- `node src/cli.js validate P` — 0 ошибок; `node src/cli.js build P` и сравни КТП в .docx с документом: темы, порядок, число строк.
- Этап `themes:<этот МДК>` в `stages` не появляется (custom-МДК этапами не генерируется) — это правильно.

## Запрещено

- Менять названия, порядок или содержание из документа, «приводить к ПОП». Требование человека — перенести как есть.
- Подгонять часы: если часы документа ≠ план — стоп, вопрос человеку (что важнее: план или документ).

## В STATUS.md

`МДК.0N.0M перенесён из <файл>: тем N, занятий T/P, курсовой K ч; расхождения с планом: нет / …`
