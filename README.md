# rpgen — рабочая программа ПМ + ФОС одним файлом

Генератор рабочих программ профессиональных модулей СПО вместе с фондом оценочных средств — один файл .docx по шаблону РП ПМ ГБПОУ «СПЭТ».

- **Структуру строит программа:** часы из учебного плана, темы и их содержание, практические работы и виды работ практик — дословно из ПОП; распределение пар по темам, пары по 2 ч, дни производственной практики по 6 ч, семестры, конкретные формы аттестации, нумерация внутри МДК, все ЛР, оформление по шаблону СПЭТ.
- **Наполнение пишет нейросеть по этапам:** названия теоретических занятий внутри тем ПОП, задания практик, тесты, вопросы, контрольная работа, экзамен по модулю. Каждый ответ проверяется: если суммы, число занятий или совпадение с ПОП не сходятся, нейросеть получает замечания и исправляет ответ.
- **ФОС** выкладывается по элементам: каждый МДК по семестрам, затем учебная практика, производственная практика (отчёт, без зачёта), экзамен по модулю.

Подробности — в файле [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Быстрый старт

```
npm install
node src/cli.js build examples/PM01_OA-2401/project.json        # собрать пример ПМ.01

node src/cli.js new projects/PM02 --plan data/plans/OA-2401.tsv --pm ПМ.02 --pop data/pop/09.02.06_PM02.json
node src/cli.js init projects/PM02/project.json
set LLM_API_KEY=...            (Linux/macOS: export LLM_API_KEY=...)
node src/cli.js fill projects/PM02/project.json                 # или next/import — ручной режим через чат
node src/cli.js build projects/PM02/project.json
```

## Состав

| Путь | Назначение |
|---|---|
| `src/plan.js` | разбор учебного плана (TSV из Excel) |
| `src/skeleton.js` | каркас: часы по МДК и семестрам, темы ПОП, распределение пар |
| `src/sequence.js` | порядок занятий в темах и разбиение МДК по семестрам |
| `src/stages.js` | этапы наполнения: промпт, проверка ответа, запись |
| `src/llm.js` | клиент API: OpenAI-совместимые (Qwen, DeepSeek, Ollama, LM Studio…) и Anthropic |
| `src/validate.js` | итоговая проверка всех правил, включая совпадение с ПОП |
| `src/build.js` | сборка .docx по шаблону СПЭТ: разделы 1–4 + раздел 5 ФОС |
| `prompts/` | тексты промптов, можно править |
| `data/fgos/` | ФГОС: ОК, ВД, ПК, реквизиты приказа |
| `data/pop/` | ПОП: разделы, темы, содержание, работы, результаты, критерии, помещения, литература |
| `data/vospitanie/` | ЛР программы воспитания и соответствие ОК–ЛР |
| `data/plans/` | учебные планы |
| `examples/PM01_OA-2401/` | готовый пример: ПМ.01, группа ОА-2401 |
