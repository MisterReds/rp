# rpgen — рабочая программа ПМ + ФОС одним файлом

Генератор рабочих программ профессиональных модулей СПО вместе с фондом оценочных средств — один файл .docx, по требованиям ГБПОУ «СПЭТ».

- **Структуру строит программа:** часы из учебного плана, пары по 2 ч, дни производственной практики по 6 ч, семестры, формы аттестации, нумерация внутри МДК, ЛР, оформление, содержание с номерами страниц.
- **Наполнение пишет нейросеть по этапам:** темы, занятия, тесты, вопросы, экзамен. Каждый ответ проверяется: если суммы или формат не сходятся, нейросеть получает замечания и исправляет ответ.

Подробности — в файле [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Быстрый старт

```
npm install
node src/cli.js build examples/PM01_OA-2401/project.json        # собрать пример ПМ.01

node src/cli.js new projects/PM02 --plan data/plans/OA-2401.tsv --pm ПМ.02
node src/cli.js init projects/PM02/project.json
set LLM_API_KEY=...            (Linux/macOS: export LLM_API_KEY=...)
node src/cli.js fill projects/PM02/project.json                 # или next/import — ручной режим через чат
node src/cli.js build projects/PM02/project.json
```

## Состав

| Путь | Назначение |
|---|---|
| `src/plan.js` | разбор учебного плана (TSV из Excel) |
| `src/skeleton.js` | каркас: бюджеты часов по МДК, семестрам, практикам |
| `src/stages.js` | этапы наполнения: промпт, проверка ответа, запись |
| `src/llm.js` | клиент API: OpenAI-совместимые (Qwen, DeepSeek, Ollama, LM Studio…) и Anthropic |
| `src/validate.js` | итоговая проверка всех правил |
| `src/build.js` | сборка .docx: РП + ФОС (приложение 1) |
| `prompts/` | тексты промптов, можно править |
| `data/fgos/` | ФГОС: ОК, ВД, ПК |
| `data/vospitanie/` | ЛР программы воспитания и соответствие ОК–ЛР |
| `data/plans/` | учебные планы |
| `examples/PM01_OA-2401/` | готовый пример: ПМ.01, группа ОА-2401 |
